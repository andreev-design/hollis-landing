# Hollis — AI Support Agent Landing Page

Landing page for Hollis, an AI customer support agent for Shopify brands. Hollis resolves customer requests end to end: it tracks orders, issues refunds, reships packages and replies across chat, email, Instagram and WhatsApp.

**Live site:** https://andreev-design.github.io/hollis-landing/

## What's inside

- Hero section with a clear value proposition and primary calls to action
- Animated ticket demo showing Hollis handle a customer request from start to finish
- "Without / With Hollis" comparison with an animated ticket counter
- Three-step onboarding flow: connect the store, set rules and tone, go live
- Features block covering channels, rules and approvals, human handoff and analytics
- Integrations, testimonials and usage-based pricing plans
- Interactive FAQ accordion and a demo request form
- Fully responsive layout for desktop, tablet and mobile
- Scroll-triggered animations throughout the page

## Tech

HTML, CSS and vanilla JavaScript. No frameworks, no build step.
